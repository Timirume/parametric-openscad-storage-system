# Parametric Storage Container (OpenSCAD)

A fully parametric dual-taper storage system designed in OpenSCAD with a matching snap-fit lid.

## Features
- Fully parametric dimensions
- Dual-stage tapered geometry
- Manufacturing-ready wall thickness control
- Built-in lid clearance system
- Modular OpenSCAD structure

## Parameters
- Base, mid, and top dimensions adjustable
- Wall thickness configurable
- Clearance for real-world 3D printing fit
